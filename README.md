# DONALD LA D VPN

Application Android de démonstration basée sur WireGuard.

## Utilisation
1. Installer l'APK généré par GitHub Actions.
2. Obtenir un serveur WireGuard fonctionnel.
3. Importer le fichier client `.conf` fourni par ce serveur.
4. Appuyer sur **Se connecter** et accepter la demande VPN Android.

## Important
Ce projet ne fournit pas de serveur VPN, de compte SSH, de clé privée ni de configuration WireGuard. Sans serveur actif et fichier client valide, l'application ne peut pas fournir de connexion Internet VPN.

L'APK de débogage est publié comme artefact dans l'exécution GitHub Actions **Build DONALD LA D VPN APK**.
